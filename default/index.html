    黑方胜利

    玩法规则

    围棋棋盘 · 冰壶手感 · 弹射对决

    1. 轮流弹射。每回合点住己方一颗棋子，向外拖拽瞄准并蓄力，松手弹射；棋子滑行减速后停下，回合结束。
    2. 击败敌人。把对方棋子撞出棋盘边缘即将其消灭。对方棋子全部被消灭时获胜。
    3. 平民有风险。撞飞平民会累积「平民伤亡」：每累计 3 个，你必须亲手选一颗自己的棋子下场（撞飞第 1、2 个不罚）。 罚则与弹射棋子无关——就算它自灭出界也照交。顶部棋子卡片用 3 个小格 + n/3 显示进度，第 3 格闪红即警告。
    4. 障碍圆盘。灰色大圆盘是固定不动的无限质量物体，撞上会剧烈反弹，可以利用它做折射球。
    5. 别把自己弹下去。己方棋子出界同样会被消灭，大力度要留神。
    6. 生化模式（可选）。平民会被「感染」：任何**有阵营的子力**（初始棋子，或已经被感染的子力）碰到中立平民，这个平民立刻变成那一方，并且永久锁定——之后被对方撞到也不会改回来。 被感染的平民与初始棋子完全等价：可以点选、可以弹射、计入棋子数；它自己撞到中立平民时**同样继续传播**，所以场上几乎不会出现「平民撞平民」。 状态栏显示 `剩余 / 总数`，每感染 1 个，分子分母同时 +1（3/3 → 4/4）；出局按敌我判定（被对方撞飞＝击落，自己出界＝自灭）。 撞飞平民没有任何惩罚，一方的棋子（含感染子）全部出局即告负。

    小技巧：碰撞会传递动量——用一颗棋子同时撞飞两颗敌方棋子，或借障碍盘改变角度偷袭。
